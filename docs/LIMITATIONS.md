# Limitations

## Cross-Sectional Data

The analysis uses cross-sectional survey data. Results describe associations in the survey outputs and do not establish causal effects.

## Survey Weighting

Weighted estimates use `WGHT_PER` for population-level interpretation. Sample counts and weighted estimates should not be mixed.

No bootstrap confidence intervals are displayed in the Power BI report layer, so smaller segment and province comparisons should be treated as descriptive.

## Pre-Aggregated Outputs

The Power BI report uses pre-aggregated analytical tables. Cross-filtering is only appropriate where a validated lookup dimension connects tables. Unrelated aggregate tables should not be interpreted as if they share respondent-level filter context.

## Channel Interpretation

Channel amount variables describe total charitable giving by channel among Health donors. They may not identify which channel was used specifically for the Health-category donation.

## Barrier Denominators

Some barriers are conditional follow-up variables with narrower denominators. They should not be compared directly with core barriers without checking denominator context.

## Predictive Model

The exploratory model is not a production fundraising model. It reports predictive associations, not causal drivers. It would require additional validation, governance, calibration, and ethical review before any operational use.

## Portfolio Context

This is an independent portfolio analysis. It is not an official Canadian Cancer Society publication and should not be treated as organizational guidance.
