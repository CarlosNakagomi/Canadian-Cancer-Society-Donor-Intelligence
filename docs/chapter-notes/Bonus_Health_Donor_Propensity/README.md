# Bonus - Health Donor Propensity

Small interpretable modeling extension. Install the shared repository dependencies from `requirements.txt`. The archived source file is available at:

```powershell
src/python/bonus_health_donor_propensity.py
```

This script preserves original chapter-folder input assumptions for upstream regeneration. The committed Power BI dashboard uses the already prepared model output tables in `outputs/powerbi/` and `powerbi/data/PowerBI_Data.xlsx`.

The model is secondary to the descriptive analysis and should not be used alone for fundraising recommendations.
