# Chapter 3 - How They Give

This chapter analyzes giving channels and giving behaviours among Health donors compared with non-Health charitable donors.

## Reproduce

Use the Chapter 2 environment or install `Chapter 2/requirements.txt`, then run from the project root:

```powershell
& "Chapter 2\.venv\Scripts\python.exe" "Chapter 3\scripts\chapter3_how_they_give.py"
```

If the local Chapter 2 `.python_packages` folder exists, the script can also use it.

## Outputs

- `docs/`: variable dictionary and methodology.
- `outputs/`: analytical tables, findings, validation results.
- `data/processed/`: respondent-level analytical extract.
- `data/powerbi/`: Power BI-ready tables.
- `sql/`: SQLite SQL views reproducing core channel aggregations.
